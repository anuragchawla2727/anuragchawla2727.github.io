Patient Readmission Analysis

Studies which patients return to hospital and why. We analysed over 100,000 diabetic patient records from 130 US hospitals using Python and advanced SQL, then built an interactive dashboard with KPIs and risk groups.

Found readmission above 48% in patients aged 70 to 90, and 68.58% in the Very High Risk group.

Predicts which bank customers are likely to leave so a team can contact them first. The model was tuned for recall because missing a leaving customer costs more than a false alarm. It runs behind a REST API with a simple web screen for non-technical users.
